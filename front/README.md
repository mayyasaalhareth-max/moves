# CineScope

تطبيق Expo / React Native لإدارة مكتبة الأفلام والممثلين وأدوارهم. يعمل على Android وiOS والويب، ويستخدم Expo Router للتنقل.

## التشغيل

```bash
npm install
npx expo start
```

## ربط الخادم

شغّل خادم الباك من مجلد `backend` بعد ضبط `MONGO_URI` في ملف `.env`:

```powershell
cd ..\backend
npm run dev
```

تتصل الشاشات بمسارات `/api/movies` و`/api/actors` و`/api/movie-actors` على المنفذ `5000`. العنوان الافتراضي هو `http://localhost:5000/api`. لتشغيل التطبيق على هاتف أو محاكي، عيّن `EXPO_PUBLIC_API_URL` إلى عنوان الخادم الذي يمكن الوصول إليه من الجهاز قبل بدء Expo:

```powershell
$env:EXPO_PUBLIC_API_URL = "http://192.168.1.10:5000/api"
npx expo start
```

استبدل العنوان بعنوان جهاز الخادم على الشبكة. محاكي Android عادةً يحتاج `http://10.0.2.2:5000/api`، أما الهاتف الفعلي فيحتاج عنوان IP المحلي للحاسوب مع السماح بالاتصال عبر جدار الحماية. بعد تغيير متغير البيئة، أعد تشغيل خادم Expo.

تتوقع الواجهة استجابات JSON بالشكل `{ "data": ... }`. أمثلة إعداد العنوان موجودة في `.env.example`.

## الأقسام

- **الأفلام:** بحث وتصنيف وتفاصيل الفيلم وطاقمه.
- **الممثلون** و**طاقم الأفلام:** تصفح وبحث.
- **لوحة التحكم:** إضافة وتعديل وحذف الأفلام والممثلين ومشاركات الطاقم.
